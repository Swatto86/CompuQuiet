      About

      CompuQuiet frees the machine for games and local AI: parks background work, switches to a performance power plan and purges cached memory. One click puts everything back, and an undo journal means a crash cannot lose the list.

      When a newer release is on GitHub and Quiet Mode is off, the Windows installer, the Linux AppImage and the macOS app download it and restart. The .deb and the portable copies stay on the version you installed.
